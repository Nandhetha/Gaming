
# Gaming OS Simulator

A C-based Gaming Operating System Simulator developed
as a college project to demonstrate operating system
concepts used in gaming environments.

## Features
- Game process management
- Priority-based CPU scheduling
- Simulated memory management
- CPU burst and scheduling statistics
- Resource monitoring dashboard in the console

## Technologies
- C Programming
- Data Structures
- Operating System Concepts
- GCC Compiler
- Visual Studio Code
- Git and GitHub

## How to Run

Compile using GCC:

    gcc main.c -o gaming_os

Run on Windows:

    gaming_os.exe

Run on Linux:

    ./gaming_os

## Modules
1. Process Manager
2. Priority Scheduler
3. Memory Manager
4. Performance Monitor

## Limitations
This project simulates operating system features.
It does not directly manage physical hardware,
real CPU execution, or actual system RAM.
